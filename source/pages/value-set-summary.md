## Value set summary

Every [value set](page:value-set) has a summary dashboard, organised into a header and cards — the same layout as the [code system summary](page:code-system-summary).

The header provides the value set name and links to:
- **Edit** — the value set form, where the value set data can be changed.
- **Concepts** — the expanded list of concepts contained in the value set.
- **Provenance** — the change history of the selected value set.
- **All versions** — a dropdown of all versions; selecting one navigates to that version summary.
- **Close** — returns to the [value set list](page:value-set-list).

Dashboard cards:
- **Value set** — general information: id, URI, description and status.
- **Versions** — all versions sorted by effective date, with their validity period, status and languages. You can add a new version or duplicate a previous one, activate/retire a version, or delete a version.
- **Related artifacts** — resources that reference the selected value set.
- **Opened tasks | All tasks** — [tasks](page:task-management) connected to the selected value set.

## Value set version summary

Each version has its own dashboard. From here you edit the [rule-based definition](page:value-set-rule-based-expansion), change the version status, expand the version to review its concepts, and download its FHIR representation.
