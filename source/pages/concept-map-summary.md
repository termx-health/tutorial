## Concept map summary

Every [concept map](page:concept-map) has a summary dashboard, organised into a header and cards — the same layout as the [code system summary](page:code-system-summary).

![Map set summary](files/tutorial/map-set-summary.png)

The header provides the concept map name and links to:
- **Edit** — the concept map form, where the concept map data can be changed.
- **Provenance** — the change history of the selected concept map.
- **All versions** — a dropdown of all versions; selecting one navigates to that version summary.
- **Close** — returns to the [concept map list](page:concept-map-list).

Dashboard cards:
- **Concept map** — general information: id, description, source and target scope.
- **Versions** — all versions sorted by effective date, with their validity period, association count and status. You can add a new version or duplicate a previous one, recompute statistics, activate/retire a version, or delete a version.
- **Related artifacts** — resources that reference the selected concept map.
- **Opened tasks | All tasks** — [tasks](page:task-management) connected to the selected concept map.

## Concept map version summary

Each version of a concept map has its own summary dashboard whose data is relevant in the context of the selected version. From here you can review the version's scope, change its status, download its FHIR representation, and open the [associations editor](page:concept-map-mapping).
