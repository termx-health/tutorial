The terminology server requires authenticated users. Any authentication server supporting OpenId Connect should suffice. For our development, we are using [Keycloak](https://www.keycloak.org/). Check the official [docs](https://www.keycloak.org/guides#getting-started) for setup. See the [authentication guide](page:authentication) for an example configuration.

Installing via Helm chart is also possible. Consider using [Bitnami chart](https://github.com/bitnami/charts/tree/master/bitnami/keycloak).
