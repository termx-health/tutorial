## Service
List of released versions: https://github.com/termx-health/termx-server/tags
### Repository
All modules are published to GitHub Packages: https://github.com/orgs/termx-health/packages?ecosystem=maven
In addition to released versions, every release has a snapshot version as in 2.4-SNAPSHOT example.
### Docker
Base docker image url: ghcr.io/termx-health/termx-server
Tags:
list of all published docker images: https://github.com/termx-health/termx-server/pkgs/container/termx-server
* `latest` - latest dev build. `ghcr.io/termx-health/termx-server:latest`
* release - same version as in released. example: `ghcr.io/termx-health/termx-server:2.3.1`
